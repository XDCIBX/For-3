# 25 Waves — память проекта для Claude

Этот файл читается в начале каждой сессии. Здесь — что за проект, как с ним работать и что уже решено.
Подробная хронология запросов и сделанного — в [`docs/HISTORY.md`](docs/HISTORY.md).

## Владелец и правила работы

- Пользователь пишет по-русски — **отвечать по-русски**, кратко и по делу, без лишнего жаргона.
- После каждой задачи: тесты (`npm test`), проверка типов (`npm run typecheck`), сборка демо
  (`cd client && npm run build:demo`), **публикация демо** — тот же файл `client/dist-demo/three-heroes.html`
  в тот же артефакт https://claude.ai/artifact/WCBt7U45ETa83gWmnTjspM, затем коммит и пуш, затем отчёт.
- Ветка разработки: `claude/2-5d-multiplayer-game-9pdxlb` (репозиторий `XDCIBX/For-3`). PR не создавать,
  пока не попросят. Ветки `main` нет. Вторая ветка `claude/practical-cerf-e23wr5` — старая копия игры.
- В конце сообщений коммитов — строки атрибуции из системных инструкций сессии; идентификаторы моделей в
  коммиты и код не писать.
- Изменения графики и анимаций проверять **скриншотами** (Playwright), баланса — **прогонами ботов**
  (`tools/sim`), а не на глаз.
- Фоновые процессы (vite, сервер) после проверки останавливать — пользователь видит «висящие» задачи.

## Что за игра

Кооперативный 2.5D-экшен на троих: 7 классов, 25 волн, общая лавка в таверне, ПвП-дуэли, финальный босс —
красный дракон. Платформы: веб, iOS/Android (Capacitor), ПК (Electron, готовится к Steam). Раньше называлась
«Три Героя»; appId мобильных `com.for3.threeheroes`, десктопа — `com.for3.twentyfivewaves`.

- **Волны:** 1–20 — остров; 21–23 — логово дракона (дракончики `drake`, огнеплюи `spitter`, огненные сгустки
  `ember`); 25 — дракон. ПвП (дуэли каждого с каждым) — волны 5, 10, 15, 20, 24. Босс тролль-вождь — на
  волнах с `isTrollRound`. Константы — `shared/src/constants.ts` (`MAX_ROUNDS`, `LAIR_ROUND`, `DRAGON_ROUND`).
- **Классы:** воин, маг, лучник, охотник на демонов, призыватель, оборотень, гном (`shared/src/data/classes.ts`).
- **Предметы:** 34 шаблона × 5 редкостей = 170 названий (`shared/src/data/items.ts`), общая лавка.
- **Пауза:** только хост; уход хоста снимает паузу; одиночная игра встаёт на паузу при сворачивании.

## Устройство (монорепо, npm workspaces)

- `shared/` — авторитетная симуляция `Game` (20 тиков/с), боты, данные, протокол, генерация мира, `Room`.
  Тесты: `shared/test/game.test.ts` (21 тест, `npm test`).
- `server/` — Node + ws: комнаты с 4-символьными кодами, раздача клиента, `/health`. Защищён от падений
  (обработчики ошибок сокета, try/catch на комнату). Сборка: `npm run build --workspace server`.
  Переменные: `PORT`, `HOST`, `TRUST_PROXY`, `MAX_ROOMS`, `MAX_CONN_PER_IP`, `ALLOWED_ORIGINS`, `HEARTBEAT_MS`,
  `APP_VERSION`; ping/pong закрывает мёртвые соединения, SIGTERM → код 1012. **Только один экземпляр**
  (комнаты в памяти). Деплой: `deploy/README.md` (VPS + Caddy в `deploy/vps`, `fly.toml`, `render.yaml`).
- `client/` — Three.js 0.180 + Vite 7. `LocalConnection` — одиночная игра прямо в браузере.
  - `render/engine.ts` — сцены, камера, качество (`low`/`high`/`ultra`), постобработка, тени.
  - `render/heroes.ts`, `mobs.ts`, `dragons.ts`, `weapons.ts`, `equipment.ts`, `anatomy.ts`, `forge.ts` —
    процедурные модели; анимации в `HeroModel.update` (позы ударов через `keyPose`).
  - `render/bake.ts` — **скелетная склейка** персонажей: анимационные группы (`userData.anim`) — кости одного
    скелета, все детали — один `SkinnedMesh` на текстуру (1–4 отрисовки на персонажа вместо 9–25). Группы,
    которые прячутся в игре (крылья демона, облик зверя, летящий молот — `userData.ownMesh` или скрытые при
    склейке), склеиваются отдельно. Геометрии **со счётчиком ссылок**, скелеты освобождаются в `releaseBaked`
    (иначе утечка видеопамяти). В вершинах — запечённое затенение (низ темнее). `toon.ts` — материалы, у
    персонажей контровой свет (`rim`, сила `CHAR_RIM` по качеству). `textures.ts` — процедурные текстуры с кэшем
    (ткань-саржа, кожа, металл, пряди `hairTex`, перепонка `membraneTex`, шкура).
  - `render/details.ts` — мелкие детали (только high/ultra, `fine()`/`finest()`): складчатые юбки, плащи,
    пряди-локоны, клочки шерсти, косы, швы, заклёпки, рёбра скелета.
  - `i18n/` — локализация, `ui/` — меню, лобби, HUD, таверна, итоги; `input/controls.ts` — джойстик,
    кнопки, клавиатура, **геймпад**.
- `desktop/` — Electron 44: протокол `app://`, полноэкранный режим, F11/Alt+Enter, `npm run dist:linux|win|mac`
  → `desktop/release/*-unpacked` (отдельный `npm ci` в `desktop/`, в workspaces не входит).
  - **Steamworks SDK 1.65** через FFI (koffi 2.16.3, без C++-аддона): `steam.cjs` (инициализация, ручной разбор
    обратных вызовов, достижения, приглашения, Rich Presence), `preload.cjs` → `window.steam`, библиотеки в
    `steam/redist/<os>`. **AppID — в `steam.config.json`** (сейчас 480 = Spacewar; таблица `achievements`
    переводит наши имена в достижения Spacewar; для релиза — свой AppID, `restartViaSteam: true`, `{}`).
    Переменная `STEAM_APP_ID` переопределяет. Без Steam игра работает как обычно.
  - Клиент: `client/src/platform/steam.ts` — достижения (`FIRST_WAVE`, `WAVE_10`, `TROLL_SLAYER`, `DUEL_WINNER`,
    `DRAGON_LAIR`, `DRAGON_SLAYER`), кнопка «Пригласить друзей Steam» в лобби, вход по `--w25-join=КОД
    --w25-server=адрес`, имя из Steam, пауза одиночной игры при открытии оверлея.
- `steam/` — тексты магазина на 7 языках, рейтинг 12+, скриншоты «Ультра» 1920×1080, капсулы (`ASSETS.md` —
  что в какое поле Steamworks), инструкция выпуска. SteamPipe — `steam/steampipe/`: **AppID и ID депо только в
  `ids.json`** (заглушки), шаблоны vdf, `make-vdf.mjs`; загрузка в `desktop.yml` (задание `steam`, секреты
  окружения `steam`), инструкция `steam/STEAMPIPE.md`.
- `tools/` — инструменты проверки (см. `tools/README.md`).
- CI: `.github/workflows/build.yml` (тесты + APK), `desktop.yml` (сборки для Steam по тегу `v*` или вручную,
  артефакты в tar.gz, загрузка через steamcmd). Адрес сервера для сборок — переменная репозитория `SERVER_URL`.

## Важные решения и правила кода

- **Локализация (7 языков: en, ru, es, de, fr, it, el).** Новый текст интерфейса: ключ в `client/src/i18n/ru.ts`,
  затем во **все** словари (тип `UiDict` не даст забыть). Игровые названия — по id в `*Data`. Сервер шлёт
  сообщения ключами (`m.*`, `why.*`, `err.*`) с параметрами, клиент переводит (`tServer`). Русские данные
  берутся из `shared/data`. Переводы делал Claude — перед релизом нужна вычитка носителями.
- **Качество графики:** `low` — без теней; `high` — статичные тени окружения; `ultra` (ПК по умолчанию) —
  живые тени героев/мобов (карта 4096 едет за камерой с привязкой к текселю), bloom + MSAA через
  EffectComposer, слабее IBL, ярче солнце, максимальная анизотропия.
- **Детализация (`render/detail.ts`):** `DETAIL.level` 1/2/3 = low/high/ultra; `seg()` множит сегменты
  геометрий, `count()` — число травы/цветов/камней/угольков. Кэши геометрий с префиксом уровня; смена качества
  сбрасывает кэш сцен (`engine.dropCachedStages`). На high/ultra кожа мобов получает `hideTex` (`toon.ts`, `HIDE_HEX`).
- **Эффекты:** пул точечных источников света (0/3/5 по качеству, без перекомпиляции шейдеров), вспышка экспозиции
  `effects.flashScreen`, плотность частиц 1/1.35/1.7, каменные шипы (`rockSpikes`) у землетрясения и прыжков.
- **Музыка (`audio/sfx.ts`):** процедурная, темы `calm`/`battle`/`tavern` (минор, спокойно), `lair` (волны 21–24,
  фригийский остинато, тайко, нарастание) и `dragon` (25). Проверка — офлайн-рендер (`OfflineAudioContext`).
- **Столкновения:** герой не толкает боссов (упирается, рывок обрывается); рывком проходит сквозь мобов,
  не таща их; клиентское предсказание тоже учитывает боссов.
- **Баланс ПвП:** таблица `DUEL_POWER` в `shared/src/sim/game.ts` — множитель урона класса по герою в дуэлях на
  каждой ПвП-волне (5/10/15/20/24); подобрана `tools/sim/tune-duel.ts` так, что при равном снаряжении все классы
  45–56 % на каждой волне (проверка — `tools/sim/pvp.ts eq`, пары — `pairs.ts`). В реальных играх ботов разница
  идёт от золота (лучник и гном зарабатывают меньше — `tools/sim/gear.ts`). При правке умений/предметов —
  перезапустить подбор. Лучник в дуэлях: выстрел ×1.1 перезарядки, ускорение 1.5.
- **Баланс:** Дракон 4700 HP,
  зовёт больше подмоги с потерей HP. Урон в логове +5 %/волну (дракон +8 %). Ориентир для ботов — ~60–75 %
  побед за 25 волн; ПвП-винрейт классов 40–60 %.
- **Производительность:** динамическое разрешение под частоту экрана (`engine.adaptResolution`): частота —
  по самым быстрым кадрам за 30 с; не успеваем за экраном — разрешение до ×0,8, ниже ~55 FPS — до ×0,5; упор в
  процессор — возврат к ×1. Шейдеры компилируются заранее (`compileAsync` при смене сцены), в релизе
  `checkShaderErrors` выключен. iOS: `CADisableMinimumFrameDurationOnPhone`; Android: `preferHighRefreshRate`
  в `MainActivity`. Замеры — `tools/browser/perf.cjs`, `drawcalls.cjs`, `adapt.cjs`.
- **Режим съёмки (dev):** `?shots=1` — фиксированное разрешение, без бейджа пинга; `engine.camOverride`,
  `engine.cleanShot`; `window.__app`, `window.__shared` доступны только в dev.

## Подводные камни

- Съёмка в «ультра» на swiftshader: один кадр 1920×1080 — 5–7 минут; запускать по одному, `TMO=` побольше.
  Docker Hub из песочницы отвечает 429 — базовый образ через `--build-arg NODE_IMAGE=mirror.gcr.io/library/node:22-alpine`;
  `npm ci` внутри docker build здесь не работает (нет прокси), проверять финальную стадию на готовых `dist`.

- Браузерные тесты идут на swiftshader (1–2 FPS): кадр ограничен 0.05 с, поэтому эффекты «отстают» от
  симуляции — в режиме `?shots=1` ограничение снято.
- Правка файлов во время браузерного прогона на dev-сервере перезагружает страницу (HMR) — не трогать код,
  пока идёт прогон.
- `pkill -f <шаблон>` может убить собственную оболочку, если шаблон встречается в команде — искать PID через `ps`.
- Electron хранит настройки в `~/.config/25 Waves` — старые настройки переживают пересборку.
- Анимации удобно проверять покадрово: `client/dev/preview.html?freeze=1&cls=...` + `window.__pose(умение, t)`
  (скрипт `tools/browser/seq.cjs`).

## Открытые задачи

- Steamworks: нужен свой AppID (замена в `desktop/steam.config.json`, достижения завести в Steamworks —
  таблица в `steam/README.md`). Оверлей и достижения проверены только на подставной библиотеке — нужна
  проверка с запущенным Steam на Windows/macOS/Linux. Сеть Valve (SDR), Steam Cloud не подключены.
- Трейлер не записан. Капсулы магазина — из арта в «высоком» качестве (композиция лучше, чем у ультра-рендеров).
- Подпись/нотаризация macOS (нужен аккаунт Apple Developer). Публичный сервер готов к деплою, но не развёрнут:
  владелец выбирает хостинг (VPS Hetzner / Fly.io / Render, `deploy/README.md`).
- Загрузка в Steam через steamcmd не проверена вживую (нужны аккаунт и AppID).
- Экономика: золото за моба — добившему; лучник и гном к 20-й волне богаче на ~25 % меньше охотника/воина,
  поэтому в реальных играх ботов слабее в ПвП (22–43 %). Можно выровнять общим золотом за помощь — не делали.
- Боты проходят 25 волн в ~75–83 % игр (выше ориентира 60–75 %) — было и до правки ПвП.
- FPS на реальных устройствах не измерен (здесь нет GPU): нужна проверка на телефоне 120 Гц и ПК 144–240 Гц.
  WKWebView на iOS может держать 60 FPS независимо от ключа в Info.plist.
- Детализация доспехов из лавки (`equipment.ts`) и обитателей логова (кроме перепонок крыльев) не трогалась.
