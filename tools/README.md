# Инструменты проверки

Не входят в сборку игры. Скрипты Playwright используют установленный глобально `playwright` и dev-сервер
клиента (`cd client && npx vite --port 5173`); картинки пишут в текущую папку — запускайте из временной.

## Симуляция и баланс (`tools/sim`, запуск из `shared/`: `npx tsx ../tools/sim/<файл>`)

| Файл | Что делает |
|---|---|
| `full25.ts` | Полные игры тремя ботами: доля побед, где проигрывают, бой с драконом. `N=24` |
| `bal.ts` | PvE-вклад классов и ПвП-винрейт каждого против каждого. Режимы `all`/`pve`/`pvp`, `PVP_REPS`, `PVE_REPS` |
| `fuzz.ts` | Стресс-тест: случайные игроки, мусорные сообщения, отключения; ищет падения, NaN, зависания. `N`, `FROM` |
| `src25.ts` | Источники урона по волнам |
| `pvp.ts [real\|eq\|both]` | ПвП по волнам 5/10/15/20/24: `real` — полные игры ботов (`N=`), `eq` — равное снаряжение, 3 комплекта (`REPS=`) |
| `tune-duel.ts` | Подбор таблицы `DUEL_POWER` (`REPS=`, `IT=`, `STEP=`), печатает значения для `game.ts` |
| `pairs.ts` | Винрейт каждой пары классов по волнам при равном снаряжении, перекосы сильнее 75/25 |
| `gear.ts` | Что набирают классы к ПвП-волнам в реальных играх: золото, характеристики, вещи |

## Браузер (`tools/browser`)

| Файл | Что делает |
|---|---|
| `steamshots.cjs <сцена> [WxH]` | Постановочные скриншоты: `island troll tavern duel lair dragon dragon2 lobby menu`; `Q=ultra`, `LANG_UI=ru`, `TMO=` тайм-аут |
| `keyart.cjs <имя> <WxH> <камера> <взгляд> [fov]` | Ключевой арт без интерфейса (дракон и герои): `T=` — момент дыхания, `Q=ultra`, `NEAR=` — убрать частицы у камеры, `TMO=` |
| `seq.cjs <имя> <query> <умение> <времена>` | Покадровая съёмка удара в `client/dev/preview.html?freeze=1` |
| `poses.cjs` | Снимки превью героев/мобов/оружия |
| `fullrun.cjs <класс>` | Прогон всех 25 волн в браузере: ошибки страницы, геометрии, текстуры, heap, FPS |
| `cycle.cjs` | Три игры подряд в одной вкладке: утечки между играми, выход через меню паузы |
| `i18n.cjs`, `langswitch.cjs` | Экраны на разных языках, смена языка посреди боя |
| `qswitch.cjs` | Переключение качества графики на лету, рывок в дракона |
| `mp_ws.cjs` | Сетевой тест сервера: 3 клиента, мусор, переподключение (`DUR=` секунд, сервер на 8799) |
| `electron.cjs` | Запуск собранной десктопной версии, геймпад, пауза |
| `preview.cjs <имя> <query> [WxH]` | Снимок `client/dev/preview.html` (`cls=`, `mobs=`, `detail=1..3`, `zoom=`, `ly=`, `rot=`) |
| `perf.cjs <качество> <волна> [WxH]` | Нагрузка кадра в бою: время JS, подготовка отрисовки, отрисовки и треугольники за кадр (с тенями) |
| `drawcalls.cjs <качество> <волна>` | Отрисовки основного прохода по владельцам: мобы, герои, помощники; на одного моба |
| `compiles.cjs <качество> <волна>` | Сколько шейдеров компилируется до боя и в первые 30 с боя, кто вызвал |
| `profile.cjs <качество> <волна>` | Профиль JS в бою: функции с наибольшим собственным временем |
| `adapt.cjs` | Динамическое разрешение на синтетических кадрах: экраны 60–240 Гц, упор в видеокарту/процессор |

## Арт для Steam (`tools/art`)

`logo.html` + `logo.cjs` — логотип «25 WAVES» с прозрачным фоном; `capsules.py` — капсулы магазина и
библиотеки из `ka_wide.png`, `ka_tall.png` (результаты `keyart.cjs`) и логотипа → `steam/art/`.

## Steam (`tools/steam`)

`mock_steam_api.c` — подставная `libsteam_api.so` (пишет вызовы в stderr, присылает «Присоединиться» и
оверлей): `gcc -shared -fPIC -o libsteam_api.so mock_steam_api.c`, положить в
`desktop/release/linux-unpacked/resources/steam/`. `electron_steam.cjs` — запуск собранной игры по
приглашению, кнопка «Пригласить», вход в другую комнату по сигналу Steam.
